실제 리딩에서 본 장면과 질문, 참여자의 답변을 통해 새롭게 발견한 내용을 기록합니다. 개인 식별 정보는 적지 마세요.

나의 학습 기록

내용은 이 기기의 브라우저에 저장됩니다. 다른 기기로 자동 전송되지 않으므로 중요한 기록은 백업하세요.

스튜디오 03 사용법

① 카드를 실제로 펼쳐 보기

카드를 고른 뒤 그림을 직접 보고, 앱의 핵심 정의와 상담자의 시선을 함께 읽어요.

② 메시지와 자기 경험 구분하기

카드를 초자연적 존재가 전하는 확정적 명령으로 다루기보다, 삶의 중요한 부분을 살펴보는 상징적 안내로 사용해요.

③ 세 장의 이야기 연결하기

현재의 자원 → 살펴볼 마음 → 오늘의 선택이라는 학습 틀을 활용해 먼저 통합 리딩을 쓰고, 이후 실제 경험을 질문으로 확인해요.

④ 내담자가 선택의 주인이 되기

참여자의 표현을 듣고 질문을 바꾸며, 무엇을 느끼고 선택할지는 참여자가 정하도록 해요.

⑤ 원자료와 연습 사례 구분하기

카드 사전의 정의·상담자의 시선·전환 질문·주의사항·기억할 문장은 첨부 PDF를 기반으로 했어요. '생활 연결 연습'은 원문의 문장을 현실에 적용해 보도록 새로 구성한 교육용 예시이며 실제 내담자 사례나 카드 원전의 문구가 아니에요.

⑥ 보관

노트와 기록은 이 브라우저 저장소에 남아요. 브라우저 데이터를 삭제하면 사라질 수 있으니 JSON 백업을 이용해요.
